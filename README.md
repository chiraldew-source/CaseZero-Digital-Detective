# 🕵️ CASE ZERO — The Digital Detective

### An Interactive Cybercrime Investigation & Mystery Game

CASE ZERO is a browser-based detective game where players investigate a fictional university data breach, examine digital evidence, interrogate suspects, and solve a mystery through logical reasoning.

## 🎯 Project Overview

**Case #CZ-001 — The Midnight Breach**

At 11:59 PM, a confidential file disappears from a university's secure server.

Three suspects. Five forensic clues. One hidden truth.

The player takes the role of a digital detective and must analyze evidence, reconstruct the timeline, and identify the culprit.

## ✨ Features

- Interactive investigation dashboard
- Digital evidence locker
- Three suspect profiles
- Incident timeline reconstruction
- Interactive suspect interrogation room
- Evidence-to-suspect connection board
- Final accusation and verdict system
- Detective scoring system
- Personalized detective case report
- Printable PDF certificate
- Responsive dark-themed interface

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The detective game will open in your browser.
5. Click **Begin Investigation** to start playing.

No backend server or API key is required.

## 🎮 How to Play

1. Begin the investigation.
2. Enter your detective codename.
3. Examine the Evidence Locker, Suspect Profiles, and Incident Timeline.
4. Question the suspects in the Interrogation Room.
5. Connect evidence cards to the relevant suspects.
6. Select your final suspect and supporting evidence.
7. Submit the final verdict.
8. View your detective score and save your case report as a PDF.

## 🏆 Detective Rankings
